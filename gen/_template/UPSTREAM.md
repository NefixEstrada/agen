# Vendored from ogen

Upstream: https://github.com/ogen-go/ogen
Version: v1.24.0
Source dir: `gen/_template`

Copied subset (schema lowering related):
- `header.tmpl`, `godoc.tmpl`, `globals.tmpl`, `jsonschema.tmpl`, `schemas.tmpl`, `json.tmpl`, `validators.tmpl`, `defaults.tmpl`
- `schema/` (SSE/stream templates excluded), `json/`, `defaults/`

Local deltas:
- header.tmpl: "Code generated by ogen" → "Code generated by agen".

agen-specific templates (not from ogen): `msg.tmpl`, `handlers.tmpl`, `client.tmpl`, `subscriber.tmpl`, `server.tmpl`, `servers.tmpl`, `operations.tmpl`, `cfg.tmpl`, `middleware.tmpl`, `unimplemented.tmpl`, `fakes.tmpl`. Of these, `client.tmpl`, `server.tmpl`, `servers.tmpl`, `operations.tmpl` and the option machinery of `cfg.tmpl` mirror ogen's public API shape (`NewClient(addr, opts...)`, `NewServer(h, opts...)`, `serverConst`, `OperationName` constants, `ServerOption`/`ClientOption` with `applyServer`/`applyClient`).

## ogen template map (30 templates + 5 subdirs vs this dir)

ogen template | here | notes
---|---|---
`cfg.tmpl` | adapted | option machinery ported (non-otel, non-HTTP parts); addresses/channel builders are agen-specific
`client.tmpl` | adapted | `NewClient(addr string, opts ...ClientOption) (*Client, error)`; ogen's `WithClient` analog is `WithPublisher`
`server.tmpl` | adapted | `NewServer(h Handler, opts ...ServerOption)`; `Run(ctx)` instead of `http.Handler` (no stdlib broker driver); only generated when every spec server shares a backend-wired protocol (redis)
`servers.tmpl` | adapted | `serverConst` shape only: AsyncAPI 3 has no server variables, so no templated-URL structs
`operations.tmpl` | adapted | `OperationName` alias + one constant per operation
`middleware.tmpl` | adapted | aliases only, like upstream (ogen's is just `type Middleware = middleware.Middleware`; `baseServer`/`baseClient` live in `cfg.tmpl`)
`handlers.tmpl`, `subscriber.tmpl`, `msg.tmpl`, `unimplemented.tmpl`, `fakes.tmpl` | agen-specific | pub/sub equivalents of ogen's HTTP-side files
`schema/`, `json/`, `defaults/`, `schemas.tmpl`, `json.tmpl`, `validators.tmpl`, `header.tmpl`, `godoc.tmpl`, `globals.tmpl`, `jsonschema.tmpl`, `interfaces.tmpl` | copied | as upstream
`faker.tmpl` + `faker/` | **not vendored** | random value fillers for example tests; needs a `with_tests` feature (deferred)
`test_examples.tmpl` | **not vendored** | spec-example round-trip tests; needs a `with_tests` feature (deferred)
`security.tmpl` | **not vendored by design** | per-operation security requirements; agen security is connection-level, delegated to backend options (DESIGN §7)
`labeler.tmpl` | **not vendored** | OTel metric attribute labelers; deferred until agen has an OTel story
`parameters.tmpl`, `parameter_decode.tmpl`, `parameter_encode.tmpl` | **N/A** | HTTP path/query/header params; agen channel address params are handled by `cfg.tmpl` builders
`request_decode.tmpl`, `request_encode.tmpl`, `response_decode.tmpl`, `response_encode.tmpl` | **N/A** | HTTP body codecs; agen's equivalents are the encode/decode halves of `msg.tmpl` (reply operations map to `response_*` in future request/reply work)
`router.tmpl` | **N/A** | topic routing lives in `subscriber.tmpl` dispatch
`uri.tmpl` + `uri/` | **N/A** | form/urlencoded object params

ogen's non-template emissions `gen_equality*.go` and `gen_validators_unique.go` (Equal/Hash methods
and hash-based uniqueItems validation for arrays of objects) are vendored at the `gen` package
level, see `internal/lowering/UPSTREAM.md`.

Re-diff per template with: `git diff --no-index <ogen>/gen/_template/<f>.tmpl gen/_template/<f>.tmpl`.
